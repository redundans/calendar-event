A [Flarum](https://flarum.org) extension. A extension for flarum.

## Installation

Install with composer:

```sh
composer require redundans/calendar-event:"*"
```

## Updating

```sh
composer update redundans/calendar-event:"*"
php flarum migrate
php flarum cache:clear
```
